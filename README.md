# trianRGBle
a rainbow triangle written in Python.
+ Should work on [Linux](https://www.linux.org/pages/download/), [Windows](https://www.microsoft.com/en-us/software-download/) & [MacOS](https://support.apple.com/en-us/102662)

## Installation and use
``` Copy & Paste this to your terminal...
git clone https://github.com/akettunen/trianRGBle.git
cd trianRGBle
python3 tRGB.py
```
> [!WARNING]
> You might need to install [Tkinter](https://docs.python.org/3/library/tkinter.html)

## Requirements
+ [Python](https://www.python.org/downloads/)
